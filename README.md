# homebrew-rythe

[Homebrew](https://brew.sh) tap for [rythe](https://github.com/apodacaa/rythe), a date/time-based
personal journal for the terminal.

```
brew install apodacaa/rythe/rythe
```

That taps this repo and installs the `rythe` command. `brew upgrade rythe` updates it. The
formula builds from the tagged release on GitHub; what rythe does is in its
[README](https://github.com/apodacaa/rythe#readme).
